# STEPFlow 관리자 v3 업데이트

이번 버전 변경사항

- 학생 표시 이름 자동 적용: `hy → 하윤`, `yjw → 윤재욱`
- 관리자 메뉴를 `오늘 / 학생 / 캘린더 / 더보기`로 전면 개편
- 오늘 화면에 재원 학생 / 입실 / 공부 중 / 확인 필요 요약
- 단순 입퇴실 알림 나열 제거, 필요할 때만 활동 기록 확인
- 확인 필요 자동 감지
  - 4시간 이상 켜진 공부 타이머
  - 이전 날짜 퇴실 누락
  - 입실 2시간 후 공부 기록 거의 없음
  - 하루 6시간 이상 단일 공부 기록
- 학생 상세에서 날짜 선택 가능
- 선택 날짜의 10분 단위 타이머 플래너 표시
- 선택 날짜 할 일 / 공부 기록 / 출결 기록 열람 및 수정
- 최근 7일 공부시간 막대 표시
- 진행 중 장기/월간/주간 계획 표시
- 관리자 공부 기록 수정 시 미기록 플랜을 해당 날짜 할 일에 연결 가능
- 더보기에서 학생 이름 수정 / 학생 추가·삭제 / 전체 JSON 백업 / 활동 로그 확인

## 배포
Cloudflare와 연결된 GitHub 저장소에서 아래 2개 파일을 교체하면 됩니다.

- `public/index.html`
- `src/index.js`

Commit 하면 Cloudflare가 자동 재배포합니다.

기존 D1 학생 데이터는 삭제하거나 다시 import할 필요가 없습니다.
