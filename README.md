# STEPFlow Offline PWA v1

이 버전은 `STEPFLOW Cloudflare 관리자 v3`를 기준으로 Android PWA 오프라인 사용을 추가한 버전입니다.

## 추가된 기능
- Android Chrome에서 앱 설치 / 홈 화면 추가
- 앱 화면 캐시: 인터넷이 없어도 STEPFlow 실행
- 학생 계정의 마지막 데이터 IndexedDB 저장
- 오프라인 공부 시작/할 일 연결/공부 종료
- 오프라인 출결 기록
- 오프라인 계획/할 일/인강 루틴 수정
- 오프라인 공부기록 수정/삭제
- 오프라인 일정 추가/삭제
- 인터넷 복구 시 작업을 순서대로 Cloudflare D1에 자동 동기화
- 상단에 `동기화됨`, `오프라인 · n개 저장 중`, `동기화 중` 표시
- 관리자 화면은 최신 서버 데이터가 중요하므로 온라인 전용

## 배포
기존 GitHub `STEPFLOW-cloudflare` 저장소에서 아래 4개 파일을 교체하세요.
- `public/index.html`
- `public/sw.js`
- `public/manifest.webmanifest`
- `src/index.js`

Commit 하면 기존 Cloudflare Git 연동이 자동 배포합니다. D1 데이터를 다시 import할 필요는 없습니다.

## 최초 사용
학생 휴대폰은 인터넷 연결 상태에서 STEPFlow에 한 번 로그인해야 합니다. 그 뒤에는 같은 기기에서 오프라인 실행이 가능합니다.

## Android 설치
Chrome으로 STEPFlow 접속 → 더보기 → `STEPFlow 앱 설치`를 누르세요. 설치 버튼이 뜨지 않는 기기는 Chrome의 `⋮` 메뉴에서 `앱 설치` 또는 `홈 화면에 추가`를 선택하면 됩니다.

## 권장 테스트
1. 온라인 상태 로그인
2. 앱 설치
3. 비행기 모드 켜기
4. 앱 완전히 종료 후 다시 실행
5. 할 일 추가 → 공부 시작 → 종료
6. 기록 탭에서 기록 확인
7. 비행기 모드 끄기
8. 상단이 `동기화됨`으로 바뀌는지 확인
9. 다른 브라우저/관리자 화면에서 해당 기록이 서버에 올라왔는지 확인

## 주의
현재는 소규모 운영을 전제로 한 `작업 큐 동기화` 방식입니다. 한 학생이 여러 휴대폰에서 동시에 오프라인 수정하는 상황은 피하는 것이 좋습니다.
