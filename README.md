# STEPFlow 스텝이 통합 디자인 v2

이번 버전은 기존 기능을 유지하면서 학생 화면에 스텝이 캐릭터 경험을 전체적으로 적용한 버전입니다.
관리자 화면에는 캐릭터를 넣지 않았습니다.

## 적용 내용
- 앱 아이콘: S + 스텝이 결합형(2안)
- 학생 앱 실행 시 약 1.3초 스플래시
- 로그인 화면 스텝이 안내
- 신규 베타 가입자 3단계 온보딩
- 홈 상단 스텝이 브리핑(공부 중/할 일/미기록/완료 상태 자동 반영)
- 공부 종료 피드백을 스텝이 말투로 변경
- 계획이 비었을 때 스텝이 빈 화면
- 캘린더 선택 날짜에 스텝이 요약
- 기록 화면에 날짜별 스텝이 요약 + 미기록 플랜 안내
- iPhone 설치 안내에 스텝이 적용
- 오프라인/동기화 문구를 스텝이 톤으로 정리
- 한 화면에 큰 스텝이 최대 1개 원칙
- 관리자 화면은 기존 운영 대시보드 유지

## 기존 기능 유지
- 정회원/베타 테스터 회원 구분
- 초대코드 회원가입 / 30명 제한
- nyj5004 전체 관리자 / manager247 베타 관리자
- 공부 타이머 / 할 일 연결 / 미기록 플랜
- 10분 타이머 플래너
- 공부 기록 수정/삭제
- 날짜별 기록 조회
- 오프라인 PWA / 자동 동기화
- 출결 / 계획 / 캘린더 / 관리자 기능

## 적용 방법
GitHub의 STEPFlow Cloudflare 저장소에서 이 ZIP 안 파일을 같은 경로에 덮어씁니다.

- public/index.html
- public/sw.js
- public/manifest.webmanifest
- public/icon-192.png
- public/icon-512.png
- public/stepi-main.png
- src/index.js

Commit 후 Cloudflare Deployments에서 최신 배포가 Success인지 확인합니다.
기존 D1 데이터는 다시 import할 필요 없습니다.

기존에 설치된 PWA 아이콘이 예전 아이콘으로 남아 있으면 홈 화면의 기존 STEPFlow를 제거한 뒤 다시 설치하면 새 아이콘이 적용됩니다.
