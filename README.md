- 초대코드: `sfbt2630`
- 초대코드 가입자는 자동으로 `베타 테스터(beta_tester)` 처리
- 베타 테스터 가입 총 한도: 30명
- 신규 관리자 `manager247` 자동 생성
  - `nyj5004`: 정회원 + 베타 테스터 전체 관리
  - `manager247`: 베타 테스터만 조회/수정/삭제/일정 관리 가능
- 관리자 화면에서 정회원/베타 배지 및 필터 제공

- `manager247`에서는 전체 데이터 백업과 관리자 캘린더를 숨기고 서버에서도 접근 차단

## 기존 데이터
기존 D1 데이터를 다시 import할 필요 없습니다.
첫 배포 후 D1의 `users` 테이블에 회원 구분/관리자 범위 컬럼이 자동 추가됩니다.
기존 학생은 기본값으로 정회원이 됩니다.

## 배포
업데이트용 ZIP의 아래 3개 파일을 GitHub의 동일 경로에 덮어씁니다.
- `public/index.html`
- `public/sw.js`
- `src/index.js`

Commit 후 Cloudflare 자동 배포가 Success인지 확인합니다.

## 확인 순서
1. 기존 `hy`, `yjw` 로그인 정상 확인
2. `nyj5004` 로그인 → 정회원/베타 통합 관리자 확인
3. `manager247` 로그인 → 베타 테스터만 보이는지 확인
4. 로그아웃 → `초대코드로 회원가입`
5. 초대코드 `sfbt2630`, 이름, 새 아이디 입력
6. 가입 후 자동 로그인 확인
7. `nyj5004`와 `manager247`에서 새 사용자가 베타 테스터로 표시되는지 확인

## 주의
현재 STEPFlow는 기존 방식대로 비밀번호 없이 로그인 아이디만으로 로그인합니다.
관리자 계정도 같은 방식이므로, 외부 공개 범위가 커지면 관리자 PIN/비밀번호 기능을 추가하는 것을 권장합니다.
